An entry for the make.fun `news-image-20261118` competition: a single picture
that sums up the world's news of Wednesday 18 November 2026.

## The image

`entry.png` (1024 × 1024) is the entry. It is a one-picture summary of the day,
drawn as a diplomatic scene in Shenzhen: two leaders already seated at a round
table, an empty chair waiting for the third, and the city skyline behind them.
The picture folds in the day's other big stories around that central scene —
Nvidia's $115.8 billion quarterly earnings, the NSA network outage, and the
tensions running through the rest of the news on 18 November 2026. The only
words on the picture are the date, the place, and two short labels, so the
image can be read at a glance.

## How to run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

That copies `entry.png` to `out/entry.png`. The program uses only the Node
standard library, needs no network access, and always writes the same bytes.
